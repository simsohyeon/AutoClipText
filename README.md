# AutoBlog — 텔레그램 → 네이버 클립 글 도우미 (반자동)

텔레그램 봇에 **사진 + 장소 이름**을 보내면, Gemini 가 사진을 보고
**네이버 클립 게시물용 글 + 해시태그**를 만들어 **복사하기 쉬운 형태**로 돌려줍니다.

폰의 네이버 클립 앱에서 사진을 고르고 글을 붙여넣어 게시하면 끝.

> ℹ️ 왜 반자동인가? 네이버 클립은 **모바일 앱으로만 업로드**가 가능하고 PC 웹 업로드를
> 지원하지 않습니다. 그래서 글 생성은 자동으로, 최종 게시(사진 선택+붙여넣기+발행)는
> 폰에서 직접 하는 방식이 가장 안정적입니다. (2025 하반기부터 클립은 영상뿐 아니라
> 이미지·텍스트 게시물도 지원합니다.)

---

## 동작 흐름

```
[텔레그램] 사진 + 장소명
      │
      ▼
[Gemini API]  사진을 직접 보고  글 + 해시태그 생성
      │
      ▼
[텔레그램] 복사 한 번으로 끝나는 글 박스 + 🔄 다시 생성 버튼
      │
      ▼
[폰 클립 앱] 사진 선택 + 붙여넣기 + 게시  (사람이 10초)
```

## 설치

```bash
npm install
cp .env.example .env   # 그리고 값 채우기
```

필요한 값:

- `TELEGRAM_BOT_TOKEN` — @BotFather 에서 봇 생성 후 발급
- `GEMINI_API_KEY` — https://aistudio.google.com → Get API key (무료, 카드 등록 불필요)
- (권장) `ALLOWED_TELEGRAM_USER_IDS` — 본인만 쓰도록 제한 (@userinfobot 으로 내 ID 확인)

## 실행

```bash
npm start
```

텔레그램에서 봇에게:

1. 음식점/카페 사진 여러 장을 보내고
2. 장소 이름을 캡션이나 텍스트로 보내면

글 박스가 옵니다. 박스를 탭 → 복사 → 클립 앱에 붙여넣기. 마음에 안 들면 **🔄 다른 느낌으로 다시**.

## 파일 구조

```
src/
├─ bot.js              진입점 (텔레그램 송수신 + 흐름)
├─ session.js          사진 묶음 모으는 debounce 버퍼 + 마지막 작업 보관(다시 생성용)
├─ config.js           .env 설정
└─ content/generate.js Gemini 로 글+해시태그 생성, 최종 캡션 조립
```

## 주의

- `.env` 에는 토큰/키가 들어가니 git 에 올리지 마세요(.gitignore 처리됨).
- 사진은 메모리에서만 처리하고 디스크에 저장하지 않습니다.
